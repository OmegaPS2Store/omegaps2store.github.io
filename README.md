# PS2 Store — Site oficial

Site estático da PS2 Store para GitHub Pages.

## Estrutura

- `index.html`: conteúdo e links.
- `style.css`: identidade visual e responsividade.
- `script.js`: atualização do ano no rodapé.
- `assets/`: logotipo e favicon.

## Publicação

Envie os arquivos para a raiz do repositório e configure Settings → Pages → Deploy from a branch → main / (root).

O Cloudflare Web Analytics está configurado no HTML.
